## Question

For the Pickleball scorekeeper UI on Apple Watch, should we just track "My Team" vs "Opponent" score, or should it fully implement Pickleball scoring rules (e.g., tracking who is serving, Server 1 vs Server 2, and the 3-number score format like 0-0-2)?

Labels: wayfinder:grilling
Status: closed

## Resolution

We will fully implement Pickleball scoring rules (0-0-2). The UI will be a split-screen design on the Apple Watch (Top = Them, Bottom = Us) with a center pill displaying the official 3-number callout and serving dots. Users tap the top or bottom half to increment scores, and a side-out button handles rotating servers and teams.
